# ARCHIVE V1 identity

V1 monogram: a broad V paired with an ascending diagonal on the numeral 1. The mark represents a first version and forward motion. It is a code-native vector with no external image or font dependency.

- Mark: `public/brand/v1-mark.svg` (64 × 64 viewBox)
- Forest sage: `#293D32`
- Ivory: `#F5F2E9`
- The shared `BrandLogo` component pairs the mark with the existing ARCHIVE V1 wordmark.
- At narrow mobile widths, the header uses the mark alone; the home link retains its accessible name.
- Browser favicon: SVG plus `public/favicon.ico` (16/32/48 px)
- PNG exports: 32, 180 (Apple touch), 192 and 512 px
- Manifest icon paths are relative to the manifest so project Pages hosting works.

Apply the same mark on the site header, loading/entry screen and HTML resume. Keep the two high-contrast colors and the original proportions.
