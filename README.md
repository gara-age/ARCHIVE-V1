# ARCHIVE V1 · Phase 2 + 가독성·성과 강조 개편

최민서의 인터랙티브 개인 아카이브. 실제로 연결된 실내에서 프로젝트, 수상, 자격증, 경험과 개인 이야기를 탐색합니다. 사용자 제공 이력서로 확인한 사실만 반영하며 미제공 자료는 명확히 구분합니다.

## 실행

```sh
npm install
npm run dev
```

http://127.0.0.1:5173

```sh
npm run build
npm run preview
npm test
```

Node.js 24 이상을 권장합니다. 테스트에서 Node의 TypeScript 타입 제거 기능으로 데이터 파일을 읽습니다.

## 차분한 첫 화면과 실제 기록 중심 구성

- 첫 화면은 ARCHIVE V1 제목, 짧은 소개, 작업실 둘러보기 버튼으로 정리했습니다. 큰 소개 패널·분야별 바로가기 카드·건수 요약은 제거했습니다.
- 수상과 자격 화면의 큰 숫자 요약 및 필터별 건수도 제거했습니다. 실제 작품명·수상명·자격 상태를 직접 보여줍니다.
- 본문 **20px**, 보조 **16px**, 큰 제목·버튼을 유지합니다. 헤더 **가+**는 본문을 24px로 확대하며 설정을 저장합니다.
- 작품 화면은 실제 발표 사진을 먼저 보여주고, 시연 영상과 미확인 상세 정보는 펼쳐 볼 수 있습니다.
- 사진을 누르면 전체 구도를 유지한 큰 이미지가 열립니다. 확대·화면 맞춤·Escape 닫기·포커스 복원을 지원하며 사진을 보는 동안 투어 이동을 막습니다.
- 목차는 버튼을 눌렀을 때만 열려 작업실 위의 불필요한 표시를 줄였습니다.

## 선정한 사진

사용자가 제공한 `수상 및 작품활동.zip`에서 네 장만 사용합니다. 비슷한 기념사진과 추가 MOV는 제외했습니다.

| 용도           | 작품     | 원본 파일                                |
| -------------- | -------- | ---------------------------------------- |
| 작품 발표 현장 | Navi     | Navi_주저자_발표사진.JPG                 |
| 실제 상장      | Navi     | Navi_한국산업기술융합학회_우수논문상.JPG |
| 작품 발표 현장 | 복지나루 | 복지나루_발표장면.jpg                    |
| 현장 수상 사진 | 복지나루 | 복지나루_현장수상사진.JPG                |

사진은 `src/data/photos.ts`, 웹 이미지는 `public/media/photos/`에서 관리합니다. 회전 정보를 바로잡고 전체 구도를 유지한 WebP 미리보기·큰 이미지를 생성했습니다. 원본 파일과 인물·사진 내용은 수정하지 않았습니다.

Navi 상장은 원문에 **우수상**으로 표기되어 있습니다. 기존 이력서의 **우수논문상** 표기는 유지하고, 상장 이미지는 원문 그대로 제공합니다. 복지나루는 현장 수상 사진으로 보여주며 별도 상장 스캔이 있다고 표시하지 않습니다.

## 시연 영상

| 작품     | 사용자 확인 대회                      | 제공 파일                      | 웹 파일                          |
| -------- | ------------------------------------- | ------------------------------ | -------------------------------- |
| Navi     | 2026 전반기 학술발표대회 · 우수논문상 | TeamS2CL-시연영상.mp4          | `/media/demos/navi-academic.mp4` |
| 복지나루 | 제10회 벤처창업경진대회 · 동상        | 폴리텍_S2CL_5페이지_동영상.mp4 | `/media/demos/bokji-venture.mp4` |

`src/data/demos.ts`에서 매핑과 포스터·설명을 관리합니다. 두 영상은 원본 1920×1080 해상도와 음성을 유지합니다. Navi는 H.264로 웹 최적화했고, 복지나루는 영상·음성 스트림을 재인코딩하지 않고 스트리밍용 MP4 구조만 정리했습니다. 원본은 수정하지 않았습니다.

`preload="none"`으로 재생 전 본 영상 다운로드를 지연하고, 자동 재생하지 않습니다. 다른 영상 재생 시 기존 영상을 멈추며 투어 구간을 이동할 때도 일시정지합니다. 실제 영상에서 추출한 포스터를 사용합니다. 자막 파일이 연결된 경우에만 자막 트랙을 제공합니다. 영상 조작 안내나 자막 미제공 안내 문구는 표시하지 않습니다.

## 구조 및 데이터 수정

- `src/data/`: 프로필·프로젝트·수상·자격·기술·경험·이야기·구간·카메라 경로
- `src/experience/`: 실내 구조, 조명, Canvas 및 범용 카메라 제어
- `src/objects/`: 책상·모니터·책장, 액자 갤러리, 트로피, 비행기, 베이킹 소품
- `src/navigation/`: Zustand 상태 머신, 휠 관성 차단, 실내 경로·화면 맞춤 계산
- `src/focus/`: 회전된 3D 화면의 좌표 투영, 확대, 포커스 복원
- `src/sections/`: 프로젝트·성과·경험·개인 정체성 콘텐츠 섹션
- `src/components/`: 전 구간 내비게이션, HTML 이력서, 사운드
- `tests/`: 입력 격리 및 카메라·투영·전체 구간 경로 검증
- `CONTENT_SOURCES.md`: 이력서와 미확인 항목의 구분
- `VALIDATION.md`: 검증 결과와 한계

## 카메라 및 렌더링

카메라 위치·포커스 표면은 `src/data/cameraRoutes.ts`, 투어 구성은 `src/data/sections.ts`에서 관리합니다. 각 표면의 회전을 반영해 HTML의 화면 영역을 투영합니다. 세로 화면에서는 FOV와 거리를 함께 조정해 카메라가 실내를 벗어나지 않도록 합니다.

카메라는 실내 중앙 경유점을 거치는 Catmull-Rom 경로를 GSAP으로 이동합니다. 전체 구간 간 정방향·역방향·목차 점프 경로를 샘플링하여 벽·바닥·천장과 메인 모니터를 관통하지 않는지 테스트합니다. 마지막은 외부 뷰가 아닌 새로운 실내 와이드샷입니다.

포커스 시 배경 Canvas를 흐리고, 투영 영역에 맞춘 선명한 전경 베젤과 HTML을 표시합니다. 전시용 액자는 목재 전경, 모니터는 어두운 베젤을 사용합니다. 실내의 비활성 액자는 아카이브 표지입니다. 정차 후 실제 제공된 발표·수상 사진과 Navi 상장을 HTML 콘텐츠에서 확인할 수 있습니다. 자격증 증빙 이미지는 아직 제공되지 않았습니다.

DPR은 1.6으로 제한하며 단일 조명에만 실시간 그림자를 사용합니다. 실제 기기 FPS는 아직 측정하지 않았습니다. 폰트는 Google Fonts 연결 실패 시 시스템 폰트로 대체됩니다.

### 나레이션

사용자가 녹음한 11개 소개 음성은 `public/media/narration`에 포함됩니다. 영역 도착 및 작품 탭 선택 시 처음부터 재생하며, 동영상과 동시에 재생하지 않습니다. 첫 방문은 로딩 완료 후 ‘작업실 들어가기’를 눌러 시작하며, 클릭과 함께 studio 음성을 재생합니다. 입장 전에는 음성 재생과 구간 이동을 막습니다. 음성 버튼은 효과음 설정과 별개이며 일반·전체화면 툴바에서 사용할 수 있습니다. 처리 기록은 `docs/narration-processing.json`, 로컬 보정 코드는 `scripts/process-narration.py`에 있습니다.

### 3D 자동 복구

WebGL 연결 손실이나 3D 초기화 오류가 생기면 현재 구간을 유지하고 3D 캔버스를 자동으로 다시 만듭니다. 연속 오류는 최대 두 번 재시도하며, 복구한 세션에서는 해상도 비율을 1로 낮춰 GPU 부담을 줄입니다. 복구 중에는 음성과 이동을 멈추고 준비 후 다시 이어갑니다. 재시도까지 실패하면 HTML 이력서로 전환합니다.

### GitHub Pages 배포

외부 접속 주소: https://gara-age.github.io/ARCHIVE-V1/

main 푸시 시 `.github/workflows/pages.yml`이 Node.js 24에서 `npm ci` → `npm test` → Pages 경로로 빌드 → 배포를 진행합니다. 이미지·영상·나레이션·3D 텍스처는 `assetUrl`로 배포 경로를 반영합니다. 로컬 개발은 기존대로 `npm ci`, `npm run dev`를 사용합니다. Pages와 같은 경로를 로컬에서 확인하려면 `VITE_BASE_PATH=/ARCHIVE-V1/ npm run build` 후 같은 환경변수로 `npm run preview`를 실행하고 `/ARCHIVE-V1/`에 접속합니다.
