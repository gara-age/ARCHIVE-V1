#### 기획 배경

기존 키오스크의 동일한 화면과 조작 방식은 작은 글씨나 복잡한 메뉴가 어려운 고령자, 높은 화면에 손이 닿기 어려운 휠체어 이용자에게 제약이 됩니다.

가족의 시력 저하를 가까이에서 경험하며 이러한 불편함에 관심을 갖게 되었습니다. 사용자가 기계에 맞추는 대신, 기계가 사용자에게 맞춰지는 서비스를 만들고자 기획했습니다. 신체적 접근성과 정보 접근성을 함께 개선하는 것이 목표였습니다.

#### 핵심 기능과 설계

- **사용자에게 맞추는 화면**

사용자의 위치와 시점을 인식해 주요 조작 요소를 사용하기 편한 위치로 조정하는 적응형 인터페이스를 설계했습니다.

- **비접촉 입력과 음성 안내**

터치 조작이 어려운 사용자도 이용할 수 있도록 손동작 입력과 음성 안내 기능을 결합했습니다.

- **자연어 기반 공공정보 탐색**

제도나 민원 서비스의 정확한 이름을 몰라도 자신의 상황을 설명하면 AI가 의도를 파악하고, 공식 공공정보를 검색해 관련 제도·신청 절차·준비 서류를 안내하도록 구성했습니다.

- **근거를 제시하는 RAG 검색**

답변의 근거를 제시하고 추가 확인이 필요한 사항은 담당 기관에 문의하도록 안내해 신뢰성을 높이고자 했습니다.

#### 담당 역할과 협업

- **팀장 · 2인 팀**

프로젝트 총괄과 기획, UI/UX 및 접근성 설계, 프론트엔드 개발과 사용자 경험 구현을 담당했습니다.

- **팀원과의 역할 분담**

팀원은 RAG 기반 공공정보 검색과 백엔드·API 개발을 담당했습니다. AI 상담 기능과 서비스 통합은 함께 진행했습니다.

- **시연과 발표 준비**

기획부터 개발, 시제품 제작, 시연과 발표 준비까지 참여하며 여러 기술과 역할을 하나의 서비스로 연결했습니다.

#### 실물 키오스크 목업

실제 이용 환경을 고려해 키오스크 목업을 공동 제작했습니다. 화면 높이와 배치, 기기 구조, 조립 및 운반 방식까지 검토하며 아이디어를 실제 시연 가능한 형태로 구체화했습니다.

#### 배운 점

기술적으로 구현 가능한 기능과 실제 사용자에게 편리한 기능은 반드시 일치하지 않는다는 점을 배웠습니다.

사용자의 신체적 조건과 정보 이해 수준을 고려해 문제를 정의하고, 이를 UI 설계와 기능 구현으로 연결하는 경험을 쌓았습니다.

#### 기획 배경

컴퓨터에서 하나의 작업을 마치려면 여러 화면을 이동하고, 버튼을 선택하고, 검색어를 입력하는 과정을 직접 수행해야 합니다.

사용자가 세부 조작 과정을 지시하는 대신 원하는 목표만 자연어로 전달하면, AI가 필요한 작업을 수행하는 서비스를 기획했습니다.

#### 핵심 기능과 기술 구조

- **목표를 전달하는 음성·텍스트 명령**

사용자의 명령을 분석해 실행 가능한 단계별 작업으로 분해하고 컴퓨터를 조작하도록 설계했습니다. 예를 들어 ‘네이버 지도에서 서울역부터 송내역까지 지하철 경로를 찾아줘’라는 요청에 브라우저 실행·사이트 이동·검색어 입력·경로 탐색을 순차적으로 수행하고 결과를 안내합니다.

- **데스크톱 인터페이스와 처리 구조**

Flutter 기반 인터페이스와 Python·FastAPI를 활용했습니다. STT와 LLM을 통한 명령 해석, Playwright와 Windows UI Automation을 통한 조작, TTS 결과 안내를 결합했습니다.

- **계획 → 실행 → 검증 → 복구**

Planner가 작업을 계획하고 Executor가 조작을 수행하며, Verifier가 실행 결과를 확인하고 Recovery가 오류 발생 시 재시도하거나 대안을 탐색하는 구조를 설계했습니다. 명령 실행뿐 아니라 최종 목표 달성 여부를 확인하는 것을 중요하게 생각했습니다.

#### 담당 역할

- **프로젝트 팀장**

문제 정의와 서비스 기획, 사용자 시나리오 설계, UI/UX 및 프론트엔드 개발, 일정과 산출물 관리를 중심으로 참여했습니다.

- **현재 상태가 보이는 접근성 UI**

명령을 듣는 중·처리 중·작업 완료·오류 발생 등 상태별 시각적 피드백을 설계했습니다. 큰 글씨와 높은 명도 대비를 고려해 사용자가 시스템의 진행 상황을 이해할 수 있도록 했습니다.

#### 성과와 배운 점

프로젝트는 학술대회에서 우수논문상을 수상했습니다.

AI가 자연어를 이해하는 것과 사용자의 목표를 안정적으로 완수하는 것은 서로 다른 문제임을 배웠습니다. 웹페이지 구조 변화, 예상하지 못한 팝업, 작업 중 오류에 대응하기 위해 실행 결과 검증과 오류 복구 구조의 중요성을 고민했습니다.

사용자 입장에서 복잡한 조작 과정을 줄이는 것 역시 접근성을 개선하는 중요한 방법임을 경험했습니다. 이 경험은 이후 복지나루에서 음성 기반 사용자 경험과 접근성 문제를 더 구체적으로 다루는 밑바탕이 되었습니다.
